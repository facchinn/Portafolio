# Nazareno Facchin — Portfolio

Portfolio personal desarrollado con **Next.js, TypeScript y Framer Motion**.

## Stack

- Next.js
- React
- TypeScript
- Framer Motion
- CSS responsive

## Ejecutar localmente

```bash
npm install
npm run dev
```

Abrir `http://localhost:3000`.

## Build

```bash
npm run build
npm start
```
